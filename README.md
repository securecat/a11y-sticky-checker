# A11y sticky checker

選択したフレームのアクセシビリティをチェックして、指摘を付箋風カードとしてフレームの上か下に貼るFigmaプラグインです。

## インストール

1. リポジトリの中身を「a11y-sticky-checker」フォルダとしてダウンロードします。
2. Figmaデスクトップアプリでデザインファイルを開きます。
3. メニューから「プラグイン → 開発 → マニフェストからプラグインをインポート」を選び、`manifest.json` を指定します。
4. 「プラグイン → 開発 → A11y sticky checker」で起動します。

## プラグインの使い方

- フレームを選択して「チェックする」を押します（複数選択可）。
- 再実行すると、そのフレームの前回の付箋は自動で置き換わります。
- 「付箋を消す」で、現在のページの付箋グループをすべて削除します。
- 「使うAI」でClaudeとGeminiを切り替えられます。APIキーとモデル名はAIごとに保存されます。
- 独自のチェックリストを入れると、AIはそれを観点にして判断します。

プラグイン実行結果のイメージは [スクリーンショット](docs/screenshot/sample01.png) を参照。

## チェック内容

- 計測（正確）：テキストのコントラスト比（1.4.3）、12px未満の文字、レイヤー名から操作要素と推定した要素のサイズ（2.5.8）
- AI（目視的な判断）：色だけで情報を伝えていないか、ラベル、リンク文言、構造、テキスト以外のコントラストなど
- 任意の観点を追加可能（何も書かなければWCAG 2.2ベースの観点でチェック）

詳細は [開発仕様書](docs/spec.md) を参照。

## 制限

- 背景が画像・グラデーションのテキストはコントラストを計算できません（付箋でお知らせします）。
- 背景色はテキスト中央の位置で判定しています。
- とても縦長のフレームは画像が縮小されるため、AIの精度が下がります。
- APIキーはFigmaのclientStorage（ユーザーのPC内）に保存されます。他の人に配布する場合は、中継サーバーを挟む構成にしてください。
