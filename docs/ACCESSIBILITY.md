# アクセシビリティ

最終更新：2026-11-17

## 優先事項と目標

この文書が対象とするのは、次のとおりです。

- プラグイン画面（設定の入力と実行を行う画面）
- キャンバスに貼る付箋（チェック結果を表示するカード）

UIは WCAG 2.2 のレベル AA を目標とし、これを上限ではなく下限と考えています。AAより厳しい独自の基準もあります（[貢献者への期待](#貢献者への期待)を参照）。第三者による試験は受けていないため、これは目標であり、適合を表明するものではありません。

## 対応している環境

- Figma：デスクトップアプリ（開発用プラグインのため）
- OS：Windows、macOS で動作を確認済み
- スクリーンリーダー：プラグイン画面の読み上げを、Windows の NVDA で確認済み。macOS の VoiceOver ではまだ試していません

## 既知の制限

- Figma そのもののアクセシビリティは、A11y sticky checker の対象外です。
  - フレームの選択と、キャンバスからプラグイン画面へのフォーカスの移動は、Figma 自体の操作によります。
  - 付箋は Figma のキャンバスに置くフレームです。Figma のキャンバスは HTML で書かれていないため、付箋はスクリーンリーダーでは読み上げられません。これは付箋に限らず、キャンバスに置くものすべてに共通する Figma の性質です。

## アクセシビリティの問題を報告する

問題は [GitHub Issues](https://github.com/securecat/a11y-sticky-checker/issues) で報告してください。日本語でも英語でも構いません。

次のことを書いてもらえると助かりますが、どれも任意です。

- 何をしようとしていたか
- プラグイン画面と、キャンバスに貼られた付箋の、どちらで起きたか
- 何が起きたか、どうなると思っていたか
- OS、Figma のバージョン、A11y sticky checker のバージョン（プラグイン画面の見出しに表示しています）
- 使っている支援技術（スクリーンリーダーなど）

障害の有無や内容を書く必要はありません。スクリーンショットや録画も必須ではありません。

## 対応の流れ

A11y sticky checker は個人で開発しているため、返信や修正の期限はお約束できません。それでも、できるかぎり早く対応します。

- 報告を確認したら、Issue で返信します
- 回避策があれば、お知らせします
- 修正をリリースする前に、問題が解消したかどうかの確認をお願いすることがあります
- 修正の内容は [CHANGELOG.md](https://github.com/securecat/a11y-sticky-checker/blob/main/CHANGELOG.md) に記載します

## 貢献者への期待

ここに挙げることは、人間の貢献者にもコーディングエージェントにも、同じように求めます。

UIを変更するときは、次を守ってください。

- フォームにはネイティブの要素（`<input>`・`<select>`・`<textarea>`）を使う。`<div>` や `<span>` をボタンの代わりにしない。画面内の操作には `<button>`、ページの移動には `<a>` を使う
- `disabled` 属性を使わない
- フォーカスインジケーターを消さない（`outline: none` を使わない）
- リンクの下線を消さない
- テキストのコントラスト比は、本文で 7:1 以上、補足的なテキストで 4.5:1 以上にする。ライトテーマとダークテーマのそれぞれで満たす
- 境界線やアイコンなど、テキスト以外の要素も、隣り合う色に対して 3:1 以上にする
- コントラストが必要な要素に `opacity` を使わない
- 文字サイズは、日本語で 16px 以上、英語で 14px 以上にする
- `font-family` は `sans-serif` にする（`system-ui` は使わない）
- ステータスメッセージを自動で消さない
- 自動スクロールなど、ひとりでに動くものを作らない

変更したあとは、キーボードだけですべて操作できること、NVDA などのスクリーンリーダーで内容が正しく読み上げられることを確認してください。

このリポジトリでは、次のことにも気をつけてください。

- プラグイン画面の基本の色には、Figma が用意するテーマの CSS 変数（`--figma-color-*`）を使ってください。Figma 本体の配色やテーマに合わせるためです。独自の色に置き換えないでください
- 付箋（`code.js` の `makeCard` など）を変更するときも、上の文字サイズとコントラストの基準を守ってください。付箋の背景色は重要度ごとに違うので、すべての色で確かめてください。重要度を色だけで伝えないよう、先頭の文字も残してください
- Figma の通知（`figma.notify`）は、しばらくすると自動で消えます。実行結果やエラーは、通知だけでなく、プラグイン画面のステータス欄にも表示してください
